# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, exploit or other flaw in W3DNext, please report it privately via [GitHub private vulnerability reporting](https://github.com/eydotan/W3DNext/security/advisories/new). Avoid public channels (issues, discussions), as an exploit may be taken from a public post and used before it can be patched.

If the issue also affects the upstream [TheSuperHackers/GeneralsGameCode](https://github.com/TheSuperHackers/GeneralsGameCode) project (i.e. it is not specific to the D3D11 backend added here), please also report it to them per their [security policy](https://github.com/TheSuperHackers/GeneralsGameCode/blob/main/SECURITY.md).
